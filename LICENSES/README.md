# License scope

[English](README.md) | [Türkçe](README.tr.md)

This repository uses two permissive licenses so that hardware design files and
software tooling receive terms appropriate to their use.

## CERN-OHL-P-2.0

The [CERN Open Hardware Licence Version 2 — Permissive](../LICENSE) applies to:

- `cad/`
- `artwork/`
- `docs/`
- `media/`
- `output/`
- `assets/`, except the third-party `assets/fonts/` directory covered below
- `README.md` and `README.tr.md`
- `CONTRIBUTING.md` and `CONTRIBUTING.tr.md`

SPDX identifier: `CERN-OHL-P-2.0`

## MIT

The [MIT License](MIT.txt) applies to:

- `tools/`
- `tests/`
- `Makefile`
- automation and configuration files

SPDX identifier: `MIT`

## Third-party fonts

The DejaVu Sans font files in `assets/fonts/` retain their upstream license.
See [`assets/fonts/LICENSE.txt`](../assets/fonts/LICENSE.txt).

Unless a file states otherwise, contributions are accepted under the license
assigned to that path above.
